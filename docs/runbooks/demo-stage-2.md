# Демонстрация этапа 2

Использовать отдельный development-стек или fixture e2e. Не применять
фикстуры и тестовые миграции к production.

1. Core: собрать API/worker и применить новую миграцию command receipts.
   Admin: `make migrate`, затем пересобрать API/frontend. Worker обязателен
   для реальной проверки подключения и внешнего этапа uninstall.
2. Войти администратором, открыть установку. Нажать «Проверить подключение»,
   подтвердить диалог. Открыть операцию, дождаться classification и времени
   наблюдения. Обновить страницу — результат остаётся в DB.
3. Отключить и включить тестовую установку; проверить состояния и историю.
   Revoke — локальная инвалидация; дальнейший шаг клиента — OAuth start.
4. В «Виджетах» создать тестовую интеграцию, изменить события/redirect,
   изменить грант, выполнить ротацию. Секрет не появляется в результатах.
5. Повторить безопасную failed/dead задачу webhook.reconcile или
   widget.ping. Для других типов кнопка недоступна. Core проверяет также
   текущее состояние установки/интеграции. После подтверждения постановки
   нажать «Проверить задачу» и дождаться её результата.
6. При partial uninstall прочитать webhook_error и подтвердить новый
   восстановительный запуск. Исходный partial-результат сохраняется.
7. Viewer: команды скрыты; прямой POST — 403. Operator: uninstall и
   управление интеграциями — 403.
8. Разрыв ответа POST: UI выполняет только GET lookup request_key.
   Неопределённый исход — unknown_outcome с проверкой объекта.

Автопроверки: Admin `make check` и `make e2e`; Core
`make fmt-check vet test openapi-check integration-test activity-ci`.
Unit/PG/browser тесты используют синтетические данные и имитируют ответы
amoCRM. Настоящие OAuth credentials нужны только для отдельной проверки
на реальном тестовом аккаунте.

Решение о хранении результата и восстановлении описано в
[ADR-0009](../adr/0009-durable-admin-operations.md). На стороне Core:
[ADR-0027](../../../amocrm-pro/docs/adr/0027-admin-command-receipts.md) и
[runbook команд](../../../amocrm-pro/docs/runbooks/admin-commands.md).
