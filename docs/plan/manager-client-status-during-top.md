# Ручная смена статуса клиента во время подписки TOP

## Объём

Основа Admin `74a7ee1` и Core `375b723`. Форма карточки и команда
`PATCH /accounts/{id}/profile` блокировали изменение статуса при TOP
в состояниях `active`, `suspended` и `awaiting_users`. Снять оба
ограничения, сохранив проверку права, версии, полей и запись в историю.
Ручная смена статуса сохраняет действующие параметры подписки.

## Приёмка

- С правом изменения профиля статус редактируется во всех трёх
  состояниях TOP, текущая подписка остаётся в карточке.
- При отсутствии права сервер возвращает 403, для устаревшей версии —
  409. Успешное сохранение попадает в историю как ручная правка.

## Отчёт

Дата: 2026-11-26. Основа: Admin `74a7ee1`, Core `375b723`.

### Реализованные экраны и операции

- Редактор статуса аккаунта доступен при любой подписке TOP сотруднику
  с правом `clients.write` и возможностью изменения профиля.
- Core сохраняет правку в истории профиля, сохраняя срок, лимит и
  состояние подписки.

### Изменения контрактов и миграции

- Сохранили маршрут, формат запроса и ответа Admin API и Core.
- Для смены статуса миграции не нужны.

### Инструкция запуска и демонстрационный сценарий

- [Локальный запуск](../runbooks/local-run.md).

### Ограничения и зависимости следующего этапа

  подписки по-прежнему устанавливают статус «Наш клиент».
