# Подписка клиента
## Объём
Platform хранит пакет аккаунта и сравнивает лимит с последним успешным
наблюдением активных пользователей. Кабинет показывает и меняет пакет,
время обновления и примечание.
## Приёмка
Выдача TOP меняет статус на «Наш клиент». Единая подписка покрывает TOP
и PRO. Превышение лимита сразу приостанавливает пакет. Собственный срок
виджета сохраняется. Изменения условий доступны в истории.
## Отчёт
25.11.2026. Подписка и примечание доступны в карточке клиента.
Core проверен через публичный API виджета и менеджерский HTTP API.
Миграции Platform 000024 и Admin 000016 проверены на PostgreSQL 17.
Прошли Go race-тесты приложений, vet, 251 тест интерфейса, lint и сборка.
В Chromium проверены выдача, превышение лимита, сохранение примечания
и размещение карточек при ширине окна 1300 и 390 пикселей. Данные стенда
тестовые. Полная Docker-сборка ограничена свободным местом в Docker VM.
Для проверки сценария в кабинете откройте карточку, выдайте TOP по
тестовой сделке, затем обновите пользователей и проверьте лимит.
