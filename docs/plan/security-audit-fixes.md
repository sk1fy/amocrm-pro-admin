# Исправления внешнего аудита AUD-01–AUD-05

## Объём

База Admin: `0eac389`; Core: `59cb3f0`. Сверено 2026-09-19.

- AUD-01: ограничить память login limiter, отказ по IP без новых email.
- AUD-02/04: сериализовать изменения сотрудника; изменение, отзыв
  сессий и аудит фиксировать одной транзакцией Admin DB.
- AUD-05: различать credentials, rate limit и инфраструктурный отказ
  в API и на экране входа.
- AUD-03 в Core: обновить gRPC и проверить RPC/mTLS и зависимости.

Контракты Core admin, миграции и продуктовые команды не меняются.
Проверка production, proxy, backup и реального совместного стенда
не входит в подтверждение этих исправлений.

## Проверки

Регрессии limiter; управляемая конкуренция PostgreSQL; ошибки вставки
аудита/отзыва сессий; ошибки чтения и записи при входе; UI 401/429/5xx
и network failure. Обязательные проверки — `make check`.

## Отчёт

Дата: 2026-09-19. Изменения поверх Admin `0eac389` и Core `59cb3f0`.
Результаты ниже получены локально до публикации веток.

### Реализованные экраны и операции

- Ограниченный по памяти login limiter и безопасные сообщения входа.
- Атомарные создание/изменение сотрудника, отзыв сессий и logout.
- Регрессии конкуренции и принудительных отказов Admin DB.

### Изменения контрактов и миграции

- Admin API: уточнена семантика 401/429/500 входа; новые маршруты не нужны.
- Core admin: контракт не менялся. Миграций нет.
- Добавлены `make vulncheck` и CI-проверка Go-зависимостей.
- [ADR-0016](../adr/0016-atomic-employee-access.md).

### Запуск и демонстрация

[Локальный запуск](../runbooks/local-run.md). Вход различает неверные
credentials, частые попытки и недоступность. Сбой аудита или отзыва
сессий возвращает 500 без частичного изменения доступа.

Данные тестов — только fixtures; реальные сотрудники и amoCRM не
использовались. Production не изменялся.

### Ограничения

Govulncheck на linux/arm64, Go 1.25.14: на уровне модулей остаётся
21 запись (20 для неимпортируемых SSH/OpenPGP частей x/crypto,
одна для x/sys/windows). Уязвимые пакеты не импортируются;
исключения сканера не добавлены. В Admin обновлён x/text до v0.39.0,
в Core gRPC до v1.83.2 и x/text до v0.41.0.

Совместный E2E настоящих Admin + Core, reverse proxy и production
backup/restore остаются отдельной эксплуатационной приёмкой.
