# Каталог «Виджеты» по макету

## Объём

- Доработать шапку и колонку «Ссылки» по макету.
- Убрать справочник «Компании» и его маршруты из кабинета менеджеров.
  Прежние адреса справочника открывают «Клиентов».

- Список использует компактные фильтры и сохраняет параметры в URL.
  Статус переносится вправо от названия. Линейка остаётся слева.
- В каждой строке график за 12 месяцев и установки за 30 суток.
  Сводка и «Нет связи» берутся из того же снимка Platform.
- «Нет связи» даёт переход к аккаунту и показывает подтверждённое
  состояние. Для ручной диагностики нужны отдельное право и команда.
- Выбор способа показа подписки остаётся открытым. Версия релиза,
  «Новый» и «На проверке» требуют подтверждённых источников.

## Приёмка

- В локальном кабинете работают сводка, 12 месячных столбиков,
  поиск, фильтры, сортировка и переход в карточку.
- Сотрудник с `clients.read` без `stats.read` видит базовый список.
- Метка «Пилот» видна справа от названия. Очередь показывает
  отдельно текущие подключения с потерей авторизации.
- Снимок и счётчики совпадают между страницами. Данные стенда
  синтетические и не входят в рабочую сборку.

Admin и `codex/manager-widgets-layout` в Platform.
