# Ответственные за сделки по установкам

## Объём

В окне общей настройки сделки менеджер выбирает активных сотрудников корпоративного аккаунта для четырёх групп клиентов. Platform проверяет и версионирует назначения вместе с воронкой. Core передаёт выбранный ID в запрос создания сделки. Проверить пустые назначения, выбор по классификации и передачу через BFF.

## Проверка

Проверить контракты, миграцию Platform, обработчик создания и форму менеджера.

## Отчёт

Проверены Go-пакеты Core и Admin, согласованность OpenAPI и генерации, сборка менеджерского приложения, линтер и тесты React. Для ручной проверки откройте «Установки → Настройка сделок», выберите сотрудников для двух разных типов, сохраните и откройте диалог повторно. Сравните ответственных в новых сделках по этим типам.
