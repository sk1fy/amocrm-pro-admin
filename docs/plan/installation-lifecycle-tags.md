# Метки установок и сделок

## Объём

Очередь менеджеров получает только текущие эпизоды с серверным фильтром state. Теги подтверждённых установок совпадают по смыслу с отметками в корпоративной сделке.

## Отчёт

В очереди показываются «Установка» и «Повторная авторизация». Platform фильтрует строки до подсчёта результатов и пагинации. Core синхронизирует теги с существующей сделкой через корпоративное подключение. Проверены сборка кабинета, UI и Go-тесты. Для проверки открыть раздел «Установки» и сопоставить строку с тестовой сделкой после повторного OAuth.
