# Метки в очереди установок

## Объём

Показать под названием виджета тип повторной установки и последнее событие отключения или повторной авторизации из существующей строки Platform. Проверить сборку менеджерского приложения и тесты.

## Отчёт

В разделе «Установки» строка показывает метки по kind и last_lifecycle_event. Контракт и миграции прежние. Сборка build:managers и 17 тестов ManagerApp прошли, включая четыре сочетания типа установки и события. Тесты используют локальные фикстуры.
