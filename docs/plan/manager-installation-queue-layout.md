# Очередь установок по макету

## Объём

База Admin `1401a5c`, Platform `05b7120`. Platform уже хранит линейку
продукта и наблюдения аккаунта: название, домен и часовой пояс. Используем
также классификацию из профиля и существующую команду проверки.
Экран получает два счётчика до фильтра по проверке; курсор привязан к
прежнему снимку. Контакт и сделка ждут соответствующих источников.

## Приёмка

- Проверить семь колонок, две вкладки и один ряд основных фильтров.
- Найти установку по названию или поддомену, открыть карточку с обоих ID
  и вернуться с прежними фильтрами.
- Отметить установку проверенной и вернуть её, сверить оба счётчика.
- Проверить старый импорт и отсутствие контактных данных.

## Отчёт

Дата: 2026-11-19. База Admin: `1401a5c`. База Platform: `05b7120`.

### Реализованные экраны и операции

- Две очереди с общими счётчиками, период, поиск по аккаунту и продукту.
- Семь колонок, поля профиля, линейка продукта и две ссылки на карточку.
- Ручная отметка, возврат в очередь и дата регистрации для импорта.

### Изменения контрактов и миграции

- Admin API и Platform добавили поля аккаунта, линейку и `queue_counts`.
- Admin подставляет имя проверившего из справочника сотрудников.
- Миграция Platform 000012 перенесена из `ed75cea`. Миграций Admin нет.

### Результаты проверок

- Admin: Go-тесты, сборка, линт и 231 тест Vitest. После правки черновика
  поиска повторно прошли целевые 11 тестов.
- Core: проверки пакетов `api` и `internal/productplatform` через Docker.
- Playwright на локальном стенде: авторизация, поиск, период, ссылки и
  возврат, обе очереди, миграция импорта, курсор, проверка и её отмена,
  узкий экран. Проверка использует Admin API, Platform и PostgreSQL.
- Полный `make check` не завершён в рамках локальной приёмки.

### Демонстрационный сценарий и происхождение данных

Локальный стенд использует отдельные PostgreSQL и вымышленные аккаунты.
Начать в «Непроверенных», открыть карточку по поддомену или ID, вернуться
и проверить строку. На вкладке «Проверенные» доступно действие «Вернуть».
