# Окно приглашения сотрудника

## Объём

Основа Admin `cd994ba`, Platform `375b723`. Приглашение обслуживает
Admin API. Форма использует существующие POST создания сотрудника и GET
каталога прав. Меняется интерфейс раздела «Сотрудники».

## Приёмка

- Менеджер вводит имя, email и права в модальном окне. Создание требует
  явного подтверждения. После успеха можно пригласить ещё одного человека.
- При потере ответа окно можно закрыть и открыть. Точный повтор отправляет
  прежние данные и ключ. До повтора форма остаётся заблокированной.
- Кнопка копирования подтверждает запись по результату Clipboard API.
  При отказе браузера текст ссылки выделяется для ручного копирования.

## Отчёт

2026-11-25. Реализовано в разделе «Сотрудники» на ветке
`feature/manager-staff-invite-dialog`. Существующие контракты и схема БД
поддерживают все действия окна.

Vitest проверил 13 сценариев страницы сотрудников, включая точный повтор
после закрытия и повторного открытия, недоступность буфера обмена и
результат асинхронной записи. Тесты используют вымышленные данные.

Путь проверки вручную — «Сотрудники» → «Пригласить сотрудника».

В Chromium проверено поведение окна при ширине 390 и 1440 пикселей.
TypeScript и ESLint прошли. Локальный `make check` остановился при
загрузке зависимостей Go из-за заполненной файловой системы Docker.
