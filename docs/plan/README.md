# Текущие задачи и внешняя приёмка

Текущее устройство приложения описано в [design](../design/architecture.md),
эксплуатация — в [runbooks](../runbooks/operator.md).
Завершённые планы удалены; их прежние версии доступны в истории Git.
Локальные тесты не подтверждают состояние целевой среды.

## Открытые проверки перед выпуском

- [ ] Подтвердить соответствие работающих образов исходникам и версиям
  Core/Admin, выполнить smoke-проверки на целевой среде по
  [инструкции оператора](../runbooks/operator.md).
- [ ] Пройти живые OAuth/SDK и установленный виджет, проверить диагностику,
  восстановление, остановку прежнего writer и production cutover по
  [инструкции пилота распределения](../runbooks/lead-distribution-pilot.md).
- [ ] Для scheduler проверок подключений подтвердить пилот на одном аккаунте,
  наблюдение не менее 24 часов, затем охват 5% → 25% → 100%.
  Контролировать rate limit, latency и ложные auth errors; при проблемах
  отключить scheduler, сохранив UI polling и ручную проверку.
  Настройки и rollout — [проверки подключений](../runbooks/operator.md#проверки-подключений).
- [ ] Сверить на текущем Core восстановление внешних Activity-команд при
  потере ответа между эффектом и commit: durable intent до dispatch,
  единый command ID владельца, чтение исхода и командная идемпотентность.
  Выполнить fault-injection на актуальном коде Core.
- [ ] Подтвердить реальный restore согласованного backup, production TLS,
  reverse proxy, credentials, PostgreSQL-роли и эксплуатационный доступ.
  Процедуры — [инструкция оператора](../runbooks/operator.md).
- [ ] Выполнить нагрузочную приёмку на целевых объёмах 10⁴–10⁵ установок,
  EXPLAIN тяжёлых Core-запросов и пилот сотрудников.
- [ ] Перед выпуском получить review и зелёные проверки точных версий PR.
  Фиксировать версии, окружение и результаты внешней приёмки.

## Новая работа

Перед реализацией создать patch-план с разделами «Объём», «Приёмка»
и «Отчёт», сверить его с текущим Core и следовать
[STYLE_GUIDE.md](../STYLE_GUIDE.md). После завершения перенести действующие
инструкции в design/runbooks, результаты — в PR/CI, затем удалить план.
