## Новая работа

Перед реализацией создать patch-план с разделами «Объём», «Приёмка»
и «Отчёт», сверить его с текущим Core и следовать
[STYLE_GUIDE.md](../STYLE_GUIDE.md). Выполненные планы не задают следующую
задачу автоматически. Внешние проверки проводить по соответствующему
runbook с фиксацией версии и окружения.
