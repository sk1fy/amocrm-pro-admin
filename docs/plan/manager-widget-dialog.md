# Каталог и модальные формы виджетов

## Объём

Сверено с Core 7301b13. Данные каталога, команды Platform и правила тарифов уже существуют. Меняются представление каталога, форма создания и признак доступа к техническим секциям в профиле менеджера.

## Приёмка

Создание открывается поверх списка и сохраняет фильтры. При каждом открытии настройки скрывают технические секции до явного действия владельца. Остальные сотрудники открывают обычную форму. Метрики загружаются только после включения.

## Отчёт

- Профиль сессии различает владельца по предоставленному UUID сотрудника. Миграции не требуются.
- Создание использует модальный диалог с черновиком и подтверждением отмены. Каталог сохраняет фильтры при закрытии.
- Прошли сборка менеджерского frontend, lint, 254 теста Vitest и локальный `go test ./...`.
- В Chromium с тестовыми ответами API проверены создание, отмена, сохранение фильтра и сброс технического режима при повторном открытии на ширинах 1440 и 390 px.
- Общий `make check` остановился на `platform-contract-check` из-за нехватки места в Docker. Проверка с производственной учётной записью не проводилась.
