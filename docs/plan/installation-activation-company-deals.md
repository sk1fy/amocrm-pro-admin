# Контакт активации и сделки по установкам

## Объём

База — локальная очередь установок поверх Core `05b7120` и Admin
`1401a5c`. Core проверяет сотрудника amoCRM и передаёт Platform контакт
конкретного эпизода. Platform создаёт сделки через отдельное подключение
аккаунта компании. Admin отображает контакт, состояние и ссылку.

## Приёмка

- Форма сохраняет телефон первого подтверждённого автора активации.
- Очередь показывает имя, доступную роль и телефон у нужного эпизода.
- Запросы на повтор после неоднозначного ответа сверяют существующую
  сделку. Новый запрос на создание возможен после явного отказа.
- Архив приватной интеграции готов для ручной установки в rakurscrm.

## Отчёт

Дата: 2026-11-19. База Core `05b7120`, Admin `1401a5c`.

### Реализованные экраны и операции

- Настройки «Контроля активности 2.0» показывают профиль amoCRM и форму
  телефона. Очередь отображает контакт активировавшего сотрудника.
- Очередь показывает состояние задачи, ссылку на сделку и повтор.
- Подготовлен отдельный ZIP для ручной установки в rakurscrm.

### Изменения контрактов и миграции

Core добавляет маршрут активации, mTLS-передачу контакта и вызов записи
сделки через выбранную привязку. Platform 000013 хранит контакт, задачу
и повтор. Admin использует контракт Platform и права менеджера.

### Результаты проверок

- Пакеты Go Core и Admin, сборка и целевые тесты менеджерского UI.
- Изолированный PostgreSQL: первая активация, повтор без перезаписи,
  проверка доступа, потерянный ответ при создании и поиск той же сделки.
- В браузере с заглушками: форма, новый токен на каждый запрос и
  ограничение приватного виджета аккаунтом rakurscrm.
- Тесты клиентского виджета и проверка содержимого ZIP.

### Ограничения следующего этапа

Настоящее подключение rakurscrm и автоматизация писем ещё не включены.
Полная приёмка и выкладка отнесены к отдельному этапу.
