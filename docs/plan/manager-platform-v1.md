# A02. Admin BFF и Platform V1

## Объём

Core `47d5270` обслуживает прежние технические маршруты. Контракт
Platform V1 зафиксирован в P01 (`a7dae9a`); отдельный mTLS listener P02
(`83dd99a`) ещё не монтирует продуктовые обработчики. Admin добавляет
типизированный клиент, устойчивый intent, сверку результата и маршрут
чтения операции. Продуктовые маршруты браузера появятся вместе с
реализацией соответствующих ресурсов.

## Приёмка

- Схема совпадает с P01, клиент воспроизводимо генерируется.
- PostgreSQL и тестовый mTLS peer подтверждают запись до выполнения,
  восстановление после потери ответа и один внешний эффект.
- Смена grants и отзыв сессии действуют на следующем запросе.

## Отчёт

Дата: 2026-11-17. Контракт Platform: Core `a7dae9a`, процесс P02:
Core `83dd99a`.

### Реализованные экраны и операции

Добавлен путь чтения операции менеджера. Пакет BFF поддерживает
синхронную отметку проверки и асинхронный повтор сделки. Маршруты
их запуска в браузере появятся вместе с продуктовой реализацией.

### Изменения контрактов и миграции

- Admin API: `GET /api/v1/managers/operations/{id}`.
- Platform и Core: без изменений; схема P01 прикреплена к Admin.
- Миграция Admin: `000008_manager_platform`.
