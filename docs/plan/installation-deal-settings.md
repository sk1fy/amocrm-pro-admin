# Общая настройка сделок по установкам

## Объём

Core ff21f89 хранит настройку на каждом продукте, и обработчик сделки
выбирает её по продукту установки. Admin 96d8d0a показывает форму в
карточке виджета. Общий вариант хранится в Platform для привязки
корпоративного аккаунта, а форма открывается в разделе «Установки».

## Приёмка

- Менеджер с правом управления каталогом открывает форму из «Установок»,
  выбирает воронку и этап и видит сохранённый выбор после открытия.
- Для установок разных виджетов обработчик выбирает общий этап.
- Карточки отдельных виджетов больше не показывают форму.
- Сохранение требует актуальных метаданных и версии настройки.
