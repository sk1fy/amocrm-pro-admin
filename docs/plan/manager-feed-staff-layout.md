# Лента событий и сотрудники по макету

## Объём

- Основа Admin `2307eb9`, Platform `f31ebde`. События и история читаются
  из Platform, сотрудники и аудит обслуживаются Admin.
- Добавить необязательные подписи аккаунта и продукта из разрешённых
  записей Platform. Порядок, курсор и набор типов ленты сохраняются.
- Собрать компактную ленту с фильтрами, датой события и раскрываемыми
  подробностями. Общий компонент сохраняет режим истории клиента.
- Собрать таблицу сотрудников со сводкой действующих прав, компактное
  приглашение по email с переключателями прав и управление
  доступом из таблицы. Редактор сохраняет права
  явной командой после просмотра черновика.
- Новые типы событий, телефонный вход и групповые роли остаются
  отдельными продуктовыми решениями.

## Приёмка

- Лента сохраняет фильтры в URL, отображает доступные подписи, работает
  с неполным ответом и оставляет переходы в пределах текущих прав.
- Список сотрудников сохраняет пагинацию. Открытие
  приглашения и редактирование черновика не изменяют права сами по себе.
- Проверить локально узкий и широкий экран, штатные живые маршруты
  Admin и Platform и отдельно проверить изменения агентом Astra.

## Отчёт

Дата 2026-11-20. Локальные ветки от Admin `2307eb9` и Platform
`f31ebde`.

### Реализованные экраны и операции

- Лента с компактными строками, московскими датами, видами событий,
  курсором и раскрываемыми подробностями.
- Сотрудники с группировкой выданных прав, приглашением по email,
  версионным редактированием и переключателем доступа.
- В таблице отдельно переключаются доступ к каталогу и просмотр аудита.
  Для ленты и метрик отображаются «Да» и «Нет».

### Контракты и миграции

- Лента и история могут содержать `account_subdomain` и
  `product_display_name` при `clients.read`.
- Admin 000014 сохраняет права сотрудника при выключении доступа.
- Admin 000015 добавляет отдельное право чтения каталога и переносит
  прежний доступ.
- Сначала выпустить совместимый Admin BFF с расширенной схемой ленты,
  затем Platform, затем Admin с миграциями и новым интерфейсом.
