# Спокойный интерфейс админки

## Объём

Только frontend и документация; контракты Admin API, Core и миграции не
меняются. Сверено с `main` `c1bebb7`.

Повод — экраны выглядят как вывод наборов данных: у каждого значения
свой бейдж, у каждого блока «Актуально» и «источник: core», технические
коды и UUID в основном виде, широкие таблицы со столбцами-кнопками.
Часть уже противоречит [states.md](../design/states.md): для `fresh`
там записано «обычный вид, `observed_at` в подсказке», а интерфейс
показывает бейдж «Актуально» и строку «Обновлено…».

Решение — [ADR-0021](../adr/0021-calm-interface.md). Правила:

1. **Норма не подсвечивается.** Бейдж — только для отклонения
   (тон не `ok`). Нормальное состояние — текст с точкой тона
   (`StatusBadge variant="text"`) или не показывается, если очевидно
   из контекста (выданный грант, активная интеграция, `real`).
   `unknown` не скрывается и не рисуется как `ok`.
2. **Свежесть — только при отклонении.** `fresh`: `observed_at`
   и источник в подсказке. `stale`/`unavailable`/`unknown` — видимая
   метка, как раньше. Строка «источник: core · время» над списками
   показывается только для частично доступного источника.
3. **Одна шапка страницы.** Заголовок, короткое описание, действия
   и компактное «Обновить» справа (`PageHeader`). Отдельной строки
   «Обновить / Обновлено…» и ссылки «назад» под крошками нет.
4. **Технические детали — по запросу.** Коды задач и событий, UUID,
   ревизии, `key_version`, хост редиректа — в подсказках или
   в «Технических данных». Крошки не показывают бекенд и UUID.
5. **Фильтры компактно.** Поиск и 1–2 главных фильтра в строке,
   остальные — «Ещё фильтры». Размер страницы — в пагинации.
   Подсказка «Списки применяются сразу…» и «Нет активных фильтров»
   удалены; сброс и чипы — только при активных фильтрах.
6. **Таблицы без служебных столбцов.** Строка открывает объект;
   столбцы «Действия/Подробнее» и «открыть» удалены, действия —
   в карточке объекта.

Экраны: Обзор, Аккаунты, карточка аккаунта (шапка, Обзор, Виджеты,
Пользователи, Операции, История), карточка подключения, Виджеты,
карточка интеграции, глобальные Операции. Система и вход — только
общие компоненты.

Вне объёма: изменения агрегатов и словаря состояний на сервере,
новые поля API, тёмная тема.

## Отчёт

Дата: 2026-11-06. Коммиты: amocrm-pro-admin — ветка
`feature/ux-calm-interface`; amocrm-pro `ed1679a` (без изменений).

### Реализованные экраны и операции
- Общие компоненты: `PageHeader` с компактным обновлением (время
  в подсказке вместе с источниками), `StatusBadge` в вариантах
  `text`/`dot` и режиме `calm`, `OriginTag` (метка только для
  не-`real`), тихие `Observation` и `SourcesCaption`, `FilterBar`
  с «Ещё фильтрами» и чипами только при активных фильтрах, размер
  страницы и «Показано N» в пагинации, `Segmented`, крошки без бекенда
  и UUID.
- Обзор: полоса показателей состояния, «Требуют внимания» списком
  с действием и числом аккаунтов, использование, бекенды и фоновые
  задачи; очереди по типам и задержки — в «Технических показателях».
- Аккаунты: домен со ссылкой, под ним ID и метка тестовых данных;
  виджеты чипами с одной точкой; состояние аккаунта текстом при норме.
- Карточка аккаунта: одна шапка с причинами «Требует внимания»;
  карточки подключений без повторной строки проблем; таблица виджетов
  без столбца «Проблемы»; история называет команду операции.
- Карточка подключения: своя шапка, сводка здоровья, одна панель
  команд, результаты под ней.
- Виджеты, интеграция (идентификаторы — в «Технических данных»),
  глобальные операции и команды сотрудников; фильтр задач — быстрые
  статусы в строке, полный список статусов под «Ещё фильтры».
