# Отзывы и продление в карточке аккаунта

## Объём
Platform хранит отзыв по аккаунту и продукту. Менеджер меняет его через
команду профиля. Кабинет показывает продление отдельного тарифа только
для платного виджета вне действующего пакета. Форма выдачи получает
начальный срок три календарных месяца.

## Приёмка
Отметка переживает перезагрузку и переустановку. Контакт и проверка
установки сохраняют свои назначения. Проверяем форму и таблицу в браузере.
