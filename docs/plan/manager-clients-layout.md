# Клиенты по макету и отдельный раздел «Компании»

## Объём

Сверено с Core/Platform `4fe4412` и Admin `7ff66b0`.
Переиспользовать список аккаунтов, поиск портрета, версионный
профиль и существующие маршруты компаний. Выделить «Компании»
в отдельный раздел с сохранением переходов по прежним ссылкам.

В списке показывать ID, поддомен, название, часовой пояс как в
«Установках», активных пользователей и время их наблюдения.
Линейки текущих виджетов фильтруются по каталогу. Отсутствие
линейки у установленного виджета показывается как Trial.

Карточки фильтруют весь серверный снимок по группе и принадлежности.
Признак получения данных требует текущей авторизации и свежего списка
пользователей. Срок, истечение и пробный период amoCRM требуют
подтверждённого источника. Группы, которые от него зависят,
показываются как недоступные.

Свободный клиент обслуживается напрямую. В профиле менеджер может
указать категорию «Клиент партнёра» и название партнёра. Это ручная
атрибуция аккаунта. Способ продления выводится из классификации.

## Приёмка

- «Компании» открываются из меню и по прежним прямым ссылкам.
- Верхняя часть карточки фильтрует по группе, строка по группе
  и принадлежности. Итоги стабильны между страницами.
- ID и название открывают одну карточку, фильтры сохраняются в URL.
- Фильтры тарифа и способа продления совпадают с данными в строках.
- Неизвестная классификация, срок amoCRM и отсутствие наблюдения
  видны в интерфейсе. 0 активных пользователей отображается числом.
- Сценарии проверяются в локальном кабинете на синтетических данных.

## Отчёт

Дата: 2026-11-19. Локальные изменения веток
`codex/manager-clients-layout` на базе Core/Platform `4fe4412` и
Admin `7ff66b0`.

### Реализованные экраны и операции

- «Компании» открываются отдельным пунктом меню и по старым ссылкам.
- «Клиенты» используют сводку, составные фильтры, тарифы виджетов
  и прежние карточки аккаунта. Имя партнёра задаётся в профиле.

### Изменения контрактов и миграции

- Platform и Admin API возвращают расширенный список
  и принимают условия группы, тарифа и способа продления.
- В Platform миграция `000015_manager_clients_overview` сохраняет
  разбивку снимка и ручное назначение партнёра.

### Демонстрация и происхождение данных

Кабинет работает на `127.0.0.1:15288`. В нём синтетические
аккаунты, пользователи и компании. Данные rakurs-135 не используются.

### Ограничения

Срок и пробный период лицензии amoCRM требуют источника. До его
подключения связанные фильтры и карточки недоступны. Сборку и
сквозную проверку на rakurs-135 предстоит выполнить перед выпуском.
