# Панель настроек виджета

## Объём

Сверено с Admin `4980dec` и Platform `fbbfa0e`. Изменения в кабинете
менеджеров используют действующие маршруты каталога, карточки,
команды сохранения и метрик. Контракты и миграции остаются прежними.

- Уплотнить каталог и показать действующее пробное правило в отдельной
  колонке. Сохранить сводку, графики, очередь «Нет связи» и фильтры.
- Открывать настройки справа по прежнему адресу `product=<id>`, сохраняя
  каталог на фоне. Отдельная форма создания остаётся доступной.
- Перенести основные поля, ссылки, выбор версии тарифа, технические
  данные и метрики за период. Сохранить права и обработку команд.
- Цены, тарифные строки и продление теста вне объёма.

## Приёмка

- Клик по строке и прямая ссылка открывают настройки. Внешние ссылки
  работают независимо. Закрытие и «Назад» сохраняют состояние каталога.
- Сохранение обновляет запись по подтверждённому ответу Platform.
  Конфликты, черновики и неизвестный результат команды доступны в панели.
- Панель доступна на узком экране и с клавиатуры. Права чтения каталога
  и просмотра метрик остаются независимыми.

## Отчёт

Дата: 2026-11-22. Базовые версии: Admin `4980dec`, Platform `fbbfa0e`.

Панель и каталог проверены в Chrome на ширине 1768 и 390 px с локальными
Admin API, Platform и PostgreSQL. В каталоге использованы 52 синтетических
виджета для проверки прокрутки на второй странице. Проверены клик по
строке, прямая ссылка, закрытие с клавиатуры, «Назад» и «Вперёд»,
несохранённый черновик, внешние ссылки, сохранение, метрики за период
и сохранение предыдущего снимка при истёкшем курсоре. При закрытии
сохранены вертикальная и горизонтальная позиции прокрутки.

Сборка кабинета, линтер, 11 целевых тестов, 6 проверок изоляции сборок
и проверка ссылок документации прошли. `make check` остановился на
загрузке `oapi-codegen` из Docker из-за TLS-таймаута. Генерация контракта
Platform проверена на хосте.

В общем прогоне Vitest прошли 238 из 243 тестов. Пять проверок истекли
при ожидании интерфейса. Повтор четырёх затронутых наборов с двумя
воркерами и увеличенным таймаутом ожидания прошёл, 23 из 23 тестов.
