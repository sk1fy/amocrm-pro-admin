# Контакт в очереди установок

## Объём

Сверено с Core на базе 1444a61. Маршрут активации хранит контакт
текущего эпизода. Для «Удобных полей» имя и телефон поступают из формы
виджета, email Core читает из профиля подтверждённого сотрудника amoCRM.
Кабинет отображает телефон, имя и email из существующего контракта.

## Приёмка

- Колонка сохраняет ссылку на телефон и показывает имя и доступный email.
- Роль из исторических контактов скрыта в очереди и карточке аккаунта.
- Повтор активации сохраняет исходный контакт эпизода.
