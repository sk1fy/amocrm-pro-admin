# Тарифы в карточке виджета

## Объём

В Platform версии 7301b13 хранится подтверждённая версия тарифа. Добавляем к карточке список именованных цен за срок, отдельно от номера версии. Используем существующие права, версионирование и команды каталога. Для FREE поле пробного периода заблокировано. Добавляем подписи к ссылкам и меняем кнопку технических настроек.

## Приёмка

Несколько вариантов можно создать, изменить и удалить. Цена хранится в копейках. Прежние карточки открываются с пустым списком вариантов. Изменение цен само по себе не меняет доступы.

## Отчёт

Реализованы редактор цен, подписи ссылок и настройки через шестерёнку.
Для TOP/PRO добавлен шаг продления и подтверждение нового срока в карточке клиента.
После миграции Platform 000028 новые поля доступны через менеджерский API.
На изолированной PostgreSQL 17 проверены сохранение двух тарифов, суммы в копейках,
продление действующего и истёкшего теста, сохранение источника и точный повтор команды.
В Chromium проверены добавление и удаление вариантов, FREE и шестерёнка при ширине 390 и 1440 px.

По результатам ревью список и обзор каталога передают компактные строки без цен.
Редактор получает все варианты отдельным запросом карточки. Кнопка продления
заново читает выбранную установку и время Platform непосредственно перед показом
новой даты. Повторная проверка этих изменений завершена.

Порядок выпуска: Admin API с обновлённой схемой, миграция Platform 000028,
Platform, затем интерфейс менеджеров. Миграция добавляет поля со значениями
по умолчанию. Выбор категории FREE при создании или переходе сохраняет основание
для бесплатного доступа. Уже выданные сроки сохраняются.
