# Рабочая очередь установок и карточка клиента

## Объём

Ветка основана на `main` Admin после PR #20. Рабочий интерфейс
использует существующий BFF и наблюдения Platform. Ветка включает общую
оболочку кабинета, очередь установок и карточку аккаунта.

Карточка показывает сводку, примечание, «Наши виджеты», «Портрет клиента»,
«Аудит», «Историю» и «Пользователей». Аудит использует сохранённые даты
и заметки. Элементы, которым нужны источники контактов, сделок,
подписки, счетов и аналитики воронок, отложены вместе с вкладкой
«Установленные виджеты». Визуальная сверка с прототипом продолжится отдельно.

## Приёмка

- Переключить очередь, отсортировать по дате и открыть карточку по ID amoCRM.
- Вернуться в очередь с прежними фильтрами.
- Открыть пять вкладок карточки и найти точный эпизод из истории.
- Проверить примечание, конфликт версии и фильтры пользователей.

## Отчёт

Дата: 2026-11-19. База Admin: `f32b4ff`. База Core: `05b7120`.

### Реализованные экраны и операции

Очередь и карточка используют штатные запросы и права. В Brave на
изолированном стенде проверены очереди, все пять вкладок, эпизод из истории,
отмена редактирования и возврат с фильтром. Стенд содержит тестовые
установки и историю, прошедшие через Core и Platform.

### Изменения контрактов и миграции

Изменений в Admin API, Core, Platform и миграциях нет.

### Результаты проверок

Полный Docker-прогон на стендовой ветке выявил таймауты существующих Go-тестов
адаптера Core и создания сессии сотрудника. Go-набор отдельно прошёл
с ограниченной параллельностью. Общий Playwright-прогон был остановлен
после этих ошибок.
