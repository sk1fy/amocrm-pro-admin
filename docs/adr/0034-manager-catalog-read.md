# Право на чтение каталога виджетов

## Контекст

В «Сотрудниках» доступ к каталогу виджетов переключается независимо
от доступа к клиентам и от просмотра аудита.

## Решение

`catalog.read` разрешает менеджеру читать список и карточку виджета.
`catalog.manage` разрешает изменения через существующие команды.
Подробная сводка каталога с данными аккаунтов дополнительно требует
`clients.read` и `stats.read`. Право аудита остаётся отдельным.

Миграция 000015 выдаёт `catalog.read` тем, у кого был `clients.read`,
в том числе в сохранённом наборе при выключенном доступе.
Версии затронутых наборов увеличиваются.

## Последствия

Для совместимости Platform временно принимает прежнее право чтения
на двух внутренних маршрутах. Публичный Admin API проверяет
`catalog.read` до обращения к Platform. При выпуске готовится
совместимый Admin BFF, принимающий новые поля ленты. После него
обновляется Platform, затем Admin с миграцией 000015 и интерфейсом.
