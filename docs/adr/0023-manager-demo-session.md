# ADR-0023: локальная сессия менеджерского демо

## Контекст

HTML handoff описывает действия кабинета, но эти бизнес-контракты пока
не реализованы в Core. Существующий React-интерфейс терял изменения при
переходе между карточкой и списком.

## Решение

Менеджерское демо использует общий React provider на маршруте `/managers`.
Типизированные переходы изменяют установки, аккаунты, счета и события.
Оплата и отмена возможны только из открытого состояния счёта; резерв
бонусов возвращается при отмене. Квитанция находится вне фильтруемой строки,
поэтому остаётся видимой после перехода счёта в другой фильтр.

Демо-сотрудники проверяются отдельно от настоящего серверного RBAC.
Партнёрский режим показывает только закреплённые синтетические аккаунты.
Справочники и черновики портрета сохраняются в памяти React по ID аккаунта.
Перезагрузка страницы или выход из кабинета сбрасывает демонстрацию.

## Отклонённые варианты

- Встраивание опубликованного HTML вместо React: теряются существующие
  маршруты, доступность и проверки приложения.
- Вызов Core из демо: нет согласованного контракта финансовых операций.
- localStorage: ненужное сохранение учебных изменений между сессиями.

## Последствия

Ни один демо-платёж, контакт, роль или продление не отправляется наружу.
Настоящая авторизация и команды Core остаются без изменений.
Демо не является подтверждением production-функциональности.
