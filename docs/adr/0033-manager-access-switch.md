# Выключение менеджерского доступа из списка сотрудников

## Контекст

В таблице сотрудников нужен обратимый переключатель. Права сотрудника
должны сохраняться, а переключение должно действовать на его
менеджерский вход и сеансы.

## Решение

Версионный PATCH сотрудника принимает `access_enabled` отдельно от
`grants`. Выключение перемещает назначенные права в
`employees.manager_suspended_grants`, удаляет их из действующих
`manager_grants` и завершает менеджерские сеансы. Включение возвращает
сохранённые права. Команда и аудит выполняются в одной транзакции.
Менеджерский вход привязывает создание сеанса к прочитанной версии
прав. Технический вход и сеансы продолжают использовать свои правила.

## Последствия

Существующие записи получают пустое хранилище при миграции 000014.
У сотрудника с выключенным доступом PATCH прав обновляет сохранённый
набор. Вход становится доступен после включения. Обратная миграция
требует сначала обработать сохранённые права, чтобы не потерять их.
