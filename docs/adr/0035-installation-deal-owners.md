# Настройка ответственных за установки

Кабинет сохраняет выбранных сотрудников с воронкой и этапом одной командой с проверкой версии. Источник списка — корпоративный аккаунт amoCRM, где создаётся сделка. Platform хранит назначения для свободного клиента, клиента партнёра, нашего клиента и аккаунта без классификации. Старый формат запроса без поля owners сохраняет предыдущие назначения.
