# Общая настройка сделок в разделе «Установки»

## Контекст

Сделки по новым установкам всех виджетов должны поступать на один этап
одной воронки корпоративного аккаунта.

## Решение

Диалог «Настройка сделок» открывается из «Установок» с правом
`catalog.manage`. Admin передаёт чтение и запись в Platform и использует
существующий механизм проверки версии и результата команды.
[Решение Core](https://github.com/sk1fy/amocrm-pro/blob/main/docs/adr/0051-shared-installation-deal-settings.md).

## Последствия

Форма убрана из карточек виджетов. Возможность настроить воронку
доступна обладателю `catalog.manage` и при закрытом доступе к очереди.
