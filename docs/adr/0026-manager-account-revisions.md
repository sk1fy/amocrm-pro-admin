# 0026. Версии карточки клиента и повтор менеджерской команды

## Контекст

У «Клиентов» и «Установок» общий UUID аккаунта в Platform. В карточке
сотрудник может изменить профиль, портрет и собственный срок виджета.
Эти ресурсы изменяются независимо и могут быть открыты у нескольких
сотрудников одновременно. Ответ на запись может потеряться после commit.

## Решение

Браузер открывает карточку по UUID из Platform. URL хранит выбранную
вкладку и состояние исходного списка. Итог и курсор приходят из одного
снимка Platform. Страница пропускает в запрос поля текущего списка.

Форма фиксирует версию при первом изменении. Заметка отправляет версию
профиля, портрет использует свою версию, а срок — версию права нужного
продукта. При 409 черновик остаётся в редакторе. Перечитывание показывает
актуальную версию, после чего сотрудник может подготовить новую команду.

Admin сохраняет намерение перед вызовом Platform. Вид команды задаёт
право, цель, предусловие и способ сверки. При неясном исходе сохраняются
исходные ключ, тело и версия. BFF сверяет receipt и возвращает локальную
ссылку операции. Внутренние маршруты Platform доступны BFF по mTLS.
Права и действующая сессия проверяются перед изменением и чтением исхода.

## Последствия

Изменение в одной форме сохраняет версию остальных ресурсов. Сотрудник
может вернуться из карточки к исходному фильтру. Ответ владельца ресурса
определяет статус сохранения, а явный повтор восстанавливает исход
команды после потери ответа. Вкладка истории получает бизнес-события
после подключения маршрута Platform по P09 и A06.
