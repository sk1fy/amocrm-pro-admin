# Управление подпиской в карточке клиента
## Контекст
Менеджеру нужны условия пакета и фактическое число пользователей.
## Решение
Кабинет читает состояние подписки из карточки Platform и передаёт
команды с правом clients.renew через менеджерский BFF. Изменения
используют версию профиля и ключ идемпотентности.
## Последствия
Смена статуса при выдаче TOP подтверждается предпросмотром. Карточка
и виджет получают доступ на основании одного пакета. Условия и история
принадлежат Platform. Для выпуска нужна миграция Admin 000016.
