# Отзыв об отдельном виджете

## Контекст
При переустановке появляется новый эпизод установки. Отзыв клиента
должен оставаться доступным во всех эпизодах этого продукта.

## Решение
Platform хранит отметку по паре аккаунт и продукт. Кабинет передаёт
требуемое значение командой редактирования профиля. Сервер проверяет
принадлежность продукта аккаунту, версию профиля и право записи.

## Последствия
Повтор той же команды сохраняет её исходный результат. Вкладка может
показать отметку во всех строках продукта после одного обновления
карточки. Менеджерская проверка установки сохраняет собственный статус.
