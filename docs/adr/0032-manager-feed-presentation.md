# Подписи аккаунта и виджета в ленте

## Контекст

Лента и история используют события Platform. Поддомен и название
виджета нужны для быстрого просмотра строк. Admin проверяет ответ
Platform по закреплённой версии OpenAPI.

## Решение

Platform отдаёт подписи в необязательных полях события при наличии
`clients.read`. Admin использует те же поля в публичном контракте.
В браузере при отсутствии поддомена строку озаглавливает вид события.
При выпуске сначала обновляется Admin BFF, затем Platform. Новый
Admin принимает события из прежнего ответа Platform.

[Решение Platform](https://github.com/sk1fy/amocrm-pro/blob/main/docs/adr/0054-manager-feed-presentation.md).

## Последствия

Admin не обходит правила чтения аккаунтов и не запрашивает карточки
по одному событию. Права истории и переходов остаются независимыми
от права `feed.read`.
