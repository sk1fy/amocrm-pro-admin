# ADR-0021. Спокойный интерфейс: норма без выделения

Статус: принято. Дата: 2026-11-06.

## Контекст

Экраны показывали каждое значение бейджем, каждый блок — меткой
«Актуально» и строкой «источник: core», технические коды задач и
событий, UUID и ревизии — в основном виде. Таблицы содержали
служебные столбцы «Действия» и «открыть», фильтры — подсказки
и размер страницы. Отклонения терялись среди нормальных состояний,
а интерфейс читался как выгрузка данных.

[states.md](../design/states.md) уже требовал для `fresh` обычный вид
с `observed_at` в подсказке; интерфейс это правило нарушал.
[ADR-0004](0004-observations-and-states.md) и
[ADR-0015](0015-connection-diagnostics-ux.md) остаются в силе: честные
состояния, разбивка агрегата, центр проблем подключения.

## Решение

1. Бейдж (заливка) — только для отклонения: тон не `ok`.
   Нормальное состояние — текст с точкой тона
   (`StatusBadge variant="text"` или `calm`) либо не показывается,
   если норма очевидна из контекста: выданный грант, активная
   интеграция, происхождение `real`. `unknown` не скрывается и не
   рисуется как `ok`; в плотных списках допустима точка с подписью
   в подсказке и для вспомогательных технологий (`variant="dot"`).
2. Свежесть видна только при отклонении. Для `fresh` время наблюдения
   и источник — в подсказке блока или кнопки обновления страницы.
   `stale`, `unavailable`, `unknown` показываются как раньше.
   Строка источника над списком — только для `degraded`; отказ
   источника — баннер `SourcesBanner`.
3. Одна шапка страницы (`PageHeader`): заголовок, факты, действия и
   компактное обновление. Навигация назад — хлебные крошки; крошки не
   показывают код бекенда и UUID, а называют объект («Подключение»,
   «Интеграция», «Операция»).
4. Технические детали по запросу: коды задач и событий — в подсказке,
   UUID, ревизии, версии ключей и хосты — в «Технических данных».
5. Фильтры: поиск и главные фильтры в одной строке, остальные под
   «Ещё фильтры»; сброс и чипы только при активных фильтрах; размер
   страницы — в пагинации; навигация пагинации скрыта на единственной
   странице.
6. Таблицы без служебных столбцов: объект открывается из строки или
   главной ячейки, действия — в карточке объекта или её панели.

## Отклонённые варианты

- Удалить технические данные из интерфейса: сотрудникам поддержки
  нужны UUID и коды для обращений в разработку.
- Перенести упрощение в Admin API (новые агрегаты): меняет контракт
  ради отображения; агрегаты и словарь состояний не меняются.

## Последствия

- `StatusBadge` получает варианты `text` и `dot`; `OriginTag` скрывает
  `real`. Правила показа зафиксированы в states.md.
- Тесты, проверявшие «Актуально», «источник: …» и коды в основном
  виде, проверяют подсказки или раскрытые технические данные.
- Новый экран следует этим правилам; исключения записываются в
  screens.md с причиной.
