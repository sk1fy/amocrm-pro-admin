# Предупреждение о лимите подписки

## Контекст

[ADR-0036](0036-account-subscription.md) определяет Platform как
владельца пакета. В карточке нужно показать первое превышение и сообщить,
когда дальнейшая проверка может приостановить пакет.

## Решение

Менеджерский BFF передаёт необязательный seats_warning из карточки
Platform. Кабинет показывает предупреждение, пока пакет активен.
Для suspended карточка показывает, что превышение подтверждено повторно.
Число пользователей рядом с лимитом берётся из снимка для карточки.

## Последствия

Порядок выпуска: Admin API с расширенным контрактом, миграция Platform
000029, Platform, затем менеджерский интерфейс. Карточка поддерживает
ответы Platform без поля seats_warning.

После миграции поддерживаемые образы при откате должны принимать
seats_warning в Admin API и записывать наблюдения лимита в Platform.
Для возврата к предыдущей схеме применяется процедура восстановления
Platform из проверенного снимка.
