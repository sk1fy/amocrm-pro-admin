# ADR-0019: диагностика Digital Pipeline при разных версиях Core

## Контекст

Перенос серверных исправлений добавляет DP-счётчики в summary. Старые
версии Core и fixture могут не предоставлять этот блок. Подстановка
пустых счётчиков ошибочно сообщает, что событий нет.

## Решение

Блок digital_pipeline необязателен и nullable. Отсутствие сохраняется
как неизвестный факт. Присутствующий блок проверяется адаптером:
оба набора states обязательны, отрицательные счётчики и некорректное
время отклоняются. UI показывает пустое состояние только по подтверждённым
нулевым счётчикам. Core 401 и 403 имеют разные причины и маппинг.

## Отклонённые варианты

Обязательный новый блок нарушает совместимость. Подстановка нулей
нарушает различие отсутствующих данных и подтверждённого отсутствия.

## Последствия

Новые версии работают с прежними источниками. Секреты и raw events
не возвращаются. Наблюдение доставки не подтверждает назначение.
