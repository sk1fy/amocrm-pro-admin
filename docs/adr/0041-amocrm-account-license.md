# 0041. Тариф amoCRM в кабинете менеджеров

## Контекст

В кабинете отображался срок оплаты amoCRM из amoSTART. Источник не
покрывал дату окончания пробного периода и причину ожидания первой
сделки для аккаунта с неизвестным тарифом.

## Решение

Кабинет показывает расчёт состояния лицензии и причину ожидания
первой сделки, которые возвращает Platform. Во время пробного
периода показывается дата, полученная от виджета. После истечения
срока кабинет показывает, что состояние оплаты уточняется, пока
Platform не получит подтверждение.

Platform передаёт `amo_license_status` с источником и временем наблюдения.
Кабинет показывает неизвестную дату при явном пробном периоде без срока
и срок подтверждённой оплаты из amoSTART. При отсутствии нового поля
карточка использует прежнее наблюдение `license`.

Карточка показывает источник и время изменения статуса из
`classification_change`, а для автоматического изменения также
причину. Причина ручной команды хранится в аудите. Менеджер подтверждает
автоматический запрет командой изменения профиля с действующими правами
и версией. Для прогноза смены статуса при выдаче «Все TOP» кабинет
использует `technical_tariff` и текущую классификацию.

## Последствия

Правила работы и хранение наблюдений определяет Platform. Описание
входа и порядок выпуска находятся в [ADR Core][core] и
[руководстве Platform][runbook].

При возврате к обычному тарифу Platform восстанавливает прежний статус
и имя партнёра, пока действует автоматический запрет. Ручное решение
менеджера сохраняется на текущий технический период. Правило создания
первой сделки действует по наблюдению тарифа отдельно от статуса.
