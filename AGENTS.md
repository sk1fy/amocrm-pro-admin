# Инструкции для агентов

Перед любой работой в этом репозитории:

1. Прочитать [docs/STYLE_GUIDE.md](docs/STYLE_GUIDE.md) полностью. Это
   обязательные правила, а не рекомендации.
2. Определить активную работу по [docs/plan/README.md](docs/plan/README.md)
   и открыть соответствующий patch-план. Файлы `docs/plan/stage-1.md`–
   `stage-4.md` — историческая приёмка, не текущий backlog. Перед началом
   сверить план с актуальным кодом `../amocrm-pro` и записать фактический
   объём в раздел «Объём».
3. Работать небольшими законченными вертикальными частями: контракт →
   бекенд → интерфейс → проверка сценария. Не начинать следующую часть,
   пока текущая не проходит проверки из стайл-гайда.
4. Не использовать Laravel/Filament, не запускать CLI через shell из
   веб-запросов, не писать напрямую в таблицы чужих бекендов, не
   возвращать секреты в ответы.
5. При каждом новом поле интерфейса обновлять
   [docs/design/data-sources.md](docs/design/data-sources.md); при каждом
   новом состоянии — [docs/design/states.md](docs/design/states.md); при
   каждом архитектурном решении — новый ADR в [docs/adr/](docs/adr/).
6. По завершении patch-плана заполнить раздел «Отчёт» по шаблону из
   стайл-гайда.

Язык документации — русский; идентификаторы, код, имена файлов, коммиты —
английский. Индекс документации — [docs/README.md](docs/README.md).
